# Test BlogFlask

Test de l'aplicació Proves Unitàries i Proves d'integració
utilitzem **pytest** que és un marc de proves amb python que executa tests automàtics. S'han de definir les comprovacions amb *assert*
## Instal·lació

Instal·lar la llibreria pytest dins el nostre .venv

# Execució dels tests

Totes les ordres que heu fet servir per arribar aquí

Din el .venv

```bash
$ pip install pytest
$ pip install coverage
```
